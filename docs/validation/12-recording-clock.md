# 正式录制生命周期与单调时钟

录制进度、停止时刻、标记和光标改为基于单调时钟。首帧仍保存主屏幕的时间基准，用于对齐先启动的辅助音轨；只在首帧收到时估算一次管道延迟，后续系统时间变化不改变视频时长。

同时修复 Windows 窗口句柄以字符串传入时，user32/Koffi 不接受其类型的问题。适配层统一校验并转成安全整数或 BigInt；非法/精度丢失的句柄拒绝使用。

验证：

- 模拟系统时间向前/向后跳变，录制 elapsed、stop timestamp、pointer timestamp 不跳变。
- 使用正式 RecordingSession 录制自建窗口，检查录制检查点和光标日志；关闭目标窗口只触发一次中断，保存完整工程（约 2.43 秒）通过。
- 截图对应的实际录制工程只在工作区副本中复测：2560×1380、约 6.03 秒；64 次外观更新产生 0 次视频 seek；30 帧/1 秒短导出成功；原工程 JSON 散列不变。报告不包含原录制帧或工程内容。

报告：工作区 `analysis/results/session-lifecycle-report.json`、`real-project-report.json`。真实设备时钟漂移、混合 DPI 和其他显卡仍须各自实测。
