# 时间线批量编辑验证

支持 Ctrl/Shift 点击多选片段，Ctrl+A 全选效果，跨轨效果整体移动、复制/粘贴、删除与撤销。批量移动按源素材时间保持相对位置；冲突整批拒绝，不部分覆盖。主录制轨可多选删除，但必须保留至少一个主片段；主片段复制与批量重排不在此次实现范围。

组合布局会自动包含屏幕/摄像头伙伴，新副本使用新的共同 groupID。检查器显示多选数量，并明确参数仅作用于当前片段。文本框内保留原生快捷键。

`tests/effect-batch.test.js` 和真实编辑器 `tests/effect-editor-probe.js` 均通过：多选、批量拖动、相对位置复制粘贴、全选删除及多步撤销；保存重开后轨道和参数保持。源剪贴板接口仍使用异步文本 API。

另已完成一次 60 秒自建窗口持续录制，含遮挡、移动缩放、最小化恢复与停止，主进程观测 RSS 峰值约 146.4MiB。只录应用自建窗口；不扩大为多屏、真实音频设备或一小时实机认证。
