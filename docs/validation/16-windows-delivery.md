## 尚未关闭

- 多屏/混合 DPI、多显卡、真实设备拔插/睡眠、摄像头/麦克风/系统音频 10/60 分钟漂移与热稳定性，需要对应硬件实测。
- 任意应用的自定义光标位图识别仍可能回退到标准外形。
- 主片段支持逐个重排及多选删除；主片段批量复制/批量重排未实现。效果轨支持批量操作。
- 界面以中文为主，尚无完整英文界面与应用内自动更新；已提供本地手动升级。
- 公开发行需要完整第三方来源/许可审核、发布者签名证书与更新服务配置。当前未签名、未发布。

因此，本轮代码和本机回归已完成，整个 Windows 全硬件验收及上述明确功能限制尚不能标为全部完成。构建、启动、安装和卸载步骤见 [构建说明](../../BUILD-AND-RUN.zh-CN.md)；具体功能测试见本目录 09—15 文档。
