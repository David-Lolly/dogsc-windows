# 动画拆分验收（2026-11-15）

缩放、屏幕 3D、摄像头动画可在播放头按 S 拆分；配对动画一起拆分。Ctrl+B 始终拆分屏幕主片段。

拆分片段保存原轨道采样快照和进度，可移动、复制、删除和继续拆分。为了保持原曲线，片段参数与边缘裁切暂时锁定；检查器明确提供“解除进度保留并独立编辑”，解除后重新计算独立动画，可撤销。

首次使用提升为 Windows schema 3；写盘时一次性保留 `project.json.schema2.bak`，滚动 `.bak` 继续保留。未使用此功能的工程仍使用 schema 2。旧版拒绝 schema 3，避免误读；效果剪贴板使用 v2 标记，普通效果仍为 v1。

验证：

- `npm test`：77 项通过，包含进入/保持/退出的 151 时刻 × 3 拆分位置、重复拆分、配对拆分、复制进度、非法快照拒绝和格式备份。
- 实际 Electron 编辑器：S、锁定控件、解除、撤销/重做、v2 剪贴板、保存重开通过；探针使用隔离剪贴板。
- 实际 GPU：10 个时刻拆分前后最大通道差 0，覆盖拆分边界和退出；组合导出及 1080p60 回归通过。

机器报告保存在工作区 `analysis/results/editor-selection-report.json`、`effects-report.json`、`renderer-report.json`。这些结论限于本次 Windows 测试环境，不代表所有驱动和硬件覆盖。
