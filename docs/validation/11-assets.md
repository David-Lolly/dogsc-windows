# 素材重新定位和跨工程贴图

新增“素材”面板：显示素材可用/缺失状态，允许重新定位视频、音频、背景和贴图。新素材复制进工程内，视频重建逐帧索引；尺寸和时长检查在替换前执行，避免截断现有剪辑。预览在文件引用变化时释放旧媒体并载入新源，撤销/重做仍有效。

跨工程粘贴贴图先检查时间线冲突，再复制独立图片。复制失败或粘贴取消清理仅本次新建文件；成功后不依赖源工程。源/目标文件路径须在所属工程内，不能通过目录跳转或符号链接读取外部文件。

验证：

- `effect-assets.test.js`：拥有独立图片、按窗口隔离清理、源图片删除后目标不变。
- `asset-relink.test.js`：短视频/错误尺寸拒绝、共享源引用同步替换、现有时间线与音轨偏移不变。
- 实际编辑器：视频重新定位后预览源切换，跨工程粘贴图片后删除原图，保存重开仍可加载。

指针日志不提供手动素材替换入口；中断录制通过恢复服务处理。重新定位只验证格式、尺寸和最短时长，用户仍须选择正确的原素材。
